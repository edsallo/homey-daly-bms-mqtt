# Daly BMS для Homey Pro

**Русский** · [English instructions](README.md)

Локальный мониторинг аккумулятора Daly BMS через MQTT. Версия **1.1.17**, Homey SDK 3. Приложение только читает данные: команд управления аккумулятором в нём нет.

В версии 1.1.17 обновлены фотографии и синий цвет значка, добавлено обратное давление MQTT и сокращены повторные записи доступности. После установки зависимостей ненужные браузерные сборки, объявления типов и карты исходников известных версий автоматически перемещаются во временную резервную папку; серверный код, TLS и лицензии сохраняются. Переустанавливать уже работающие Node.js и Homey CLI не нужно. Исходные PNG и варианты JPG сохранены; в пакет Homey включены только используемые JPG.

## Для чего это приложение

Оно показывает в Homey заряд аккумулятора, напряжение, ток, температуры и данные ячеек. Показатели сохраняются на графиках Insights; доступные значения и сигналы можно использовать в Flow, например для уведомления о низком заряде. Приложение не заменяет BMS и её защиту аккумулятора.

Связка работает так: **Daly BMS → совместимая плата ESP с прошивкой для BMS → Wi-Fi/MQTT-брокер → наше приложение Homey**. Это отдельные компоненты: установка приложения Homey не прошивает ESP и не создаёт MQTT-брокер.

## Где взять прошивку ESP и зачем покупать лицензию

Прошивку разрабатывает **softwarecrash / All-Solutions**. Это отдельный проект, не часть нашего приложения:

- [Daly2MQTT: проект, документация и схема подключения](https://github.com/softwarecrash/Daly2MQTT).
- [100Daly2MQTT для 100Balance и новых Daly серий H/K/M/S](https://github.com/softwarecrash/100Daly2MQTT). Выбирайте по совместимости в документации автора, а не только по цвету корпуса BMS или току.
- [Веб-прошивальщик автора](https://flash.2mqtt.de/), ссылка на который есть в проекте прошивки. Нужна поддерживаемая плата: исходный Daly2MQTT рекомендует ESP8266/Wemos D1 Mini. Нельзя считать любой ESP32 совместимым.
- [Покупка лицензии прошивки у All-Solutions](https://all-solutions.store/en/store/license/).

**Для полного функционала лицензируемой прошивки ESP нужна платная лицензия её автора — это прямо указано для 100Daly2MQTT.** Она открывает дополнительные подробные данные и функции. Купите и активируйте её по инструкции автора. Лицензия привязана к BMS, а не к нашему приложению Homey. При покупке готового адаптера право на лицензию может входить в комплект — проверьте заказ, прежде чем платить повторно. Стоимость и условия устанавливает автор прошивки.

Само приложение Homey не требует дополнительной платной лицензии. Оно показывает только те данные, которые прошивка реально публикует в MQTT, и не снимает её ограничений. Для совместимости нужен описанный ниже формат отдельных MQTT-топиков; сама покупка лицензии не гарантирует совместимость любой прошивки.

Перед подключением изучите схему и предупреждения автора: старые Bluetooth- и новые Wi-Fi/Bluetooth-модули Daly могут иметь разную распиновку и напряжение питания. Не подключайте их кабели наугад. В прошивке выберите отдельные MQTT-топики, а не только JSON `Pack_Data`. Сначала настройте на ESP Wi-Fi, MQTT-брокер и базовый топик, затем добавляйте устройство в Homey.

## Что понадобится

- Homey Pro с прошивкой **12.0.0 или новее**, аккаунт Athom с правом установки приложений и компьютер Mac или Windows.
- Компьютер и Homey должны иметь доступ друг к другу по сети. Во время установки нужен интернет.
- Уже работающий MQTT-брокер — сервер сообщений, на который Daly2MQTT передаёт показания аккумулятора. Приложение не устанавливает брокер и не подключается к BMS напрямую по Bluetooth.
- Адрес брокера, порт, базовый топик и, если настроены, логин и пароль. Возьмите их из своих настроек MQTT/Daly2MQTT, а не подбирайте наугад.

Это ручная установка исходного кода, а не установка из магазина Homey. Просто открыть ZIP на телефоне недостаточно. Компьютер нужен для установки; после неё приложение работает на Homey самостоятельно.

## 1. Установите Node.js

1. На [nodejs.org](https://nodejs.org/en/download) скачайте установщик **LTS** для своей операционной системы.
2. Запустите его и следуйте подсказкам. В Windows оставьте включённым добавление Node.js в PATH.
3. Откройте новое окно командной строки. **Mac:** Command + пробел → наберите «Терминал» → Enter. **Windows:** «Пуск» → наберите `cmd` → «Командная строка».
4. По очереди скопируйте команды, после каждой нажимайте Enter:

   ```sh
   node --version
   ```

   ```sh
   npm --version
   ```

Обе должны показать номер версии. Если появляется «команда не найдена», закройте командную строку, откройте заново и проверьте установку Node.js.

## 2. Установите Homey CLI

Homey CLI — инструмент, который загружает приложение с компьютера в Homey. Выполните:

```sh
npm install -g homey
```

Дождитесь завершения: внизу снова появится строка для ввода. Затем проверьте:

```sh
homey --version
```

При ошибке прав доступа не меняйте системные разрешения и не добавляйте `sudo` наугад. Используйте [официальную инструкцию Homey](https://apps.developer.homey.app/the-basics/getting-started), где описан и вариант установки Node.js через менеджер версий.

## 3. Скачайте и распакуйте приложение

1. Откройте [репозиторий](https://github.com/edsallo/homey-daly-bms-mqtt), выберите ветку **main**, затем **Code → Download ZIP**.
2. Распакуйте ZIP. **Windows:** правая кнопка по архиву → «Извлечь всё». **Mac:** дважды нажмите на архив.
3. Откройте полученную папку: внутри должны быть `app.json`, `package.json` и папка `drivers`. Нужна именно эта папка, не ZIP и не папка уровнем выше.

Также можно скачать **Source code (zip)** на [странице релиза](https://github.com/edsallo/homey-daly-bms-mqtt/releases/latest). Архив релиза — зафиксированная версия; архив ветки `main` включает последние изменения репозитория.

## 4. Откройте папку приложения в командной строке

**Mac:** в Терминале наберите `cd ` — обязательно с пробелом. Перетащите распакованную папку из Finder в окно Терминала и нажмите Enter. Путь подставится автоматически.

**Windows:** откройте распакованную папку в Проводнике, нажмите на адресную строку сверху, наберите `cmd` и нажмите Enter.

Для проверки выполните `ls` на Mac или `dir` в Windows. В списке должны быть `app.json` и `package.json`.

## 5. Установите приложение в Homey

Вводите команды **по одной**, дожидаясь завершения каждой.

1. Скачайте необходимые приложению библиотеки:

   ```sh
   npm install --omit=dev
   ```

2. Войдите в аккаунт Homey:

   ```sh
   homey login
   ```

   Откроется браузер. Войдите в аккаунт Athom, которым управляете своим Homey, и подтвердите запрошенный вход. После успешного входа вернитесь в командную строку. Если браузер не открылся, воспользуйтесь ссылкой из вывода команды.

3. Выберите свой Homey:

   ```sh
   homey select
   ```

   Если появится список, выберите устройство стрелками на клавиатуре и нажмите Enter.

4. Загрузите приложение:

   ```sh
   homey app install
   ```

   Дождитесь сообщения об успешной установке. Если показана ошибка, установка ещё не завершена. Сохраните текст ошибки для проверки.

Не добавляйте `--clean`: этот параметр может удалить устройства и настройки приложения. Используйте именно `homey app install`, а не `homey app run` — последняя команда предназначена для временного запуска при разработке. После успешной установки окно можно закрыть. Для описанного способа установки Docker не нужен.

## 6. Добавьте аккумулятор в Homey

Откройте приложение Homey на телефоне → выберите свой Homey → **«Устройства» → + → Daly BMS** → выберите устройство Daly BMS. Заполните форму:

| Поле | Что указать |
|---|---|
| Название | Любое понятное имя, например «Аккумулятор» |
| Брокер | IP-адрес или имя своего MQTT-сервера, без `mqtt://` и `http://` |
| Порт | Порт вашего брокера: часто `1883` без TLS или `8883` с TLS |
| Базовый топик | Точное значение из Daly2MQTT, например `BMS01`, без `/#` |
| Логин и пароль | Данные MQTT-брокера; пустые поля допустимы, только если брокер это разрешает |
| TLS | Включите, только если брокер настроен на TLS; соответствующий порт укажите отдельно |

Нажмите кнопку добавления и дождитесь показаний. Homey должен иметь сетевой доступ к брокеру. Пример: для топика `BMS01/Pack_Voltage` базовый топик — `BMS01`. Любой адрес в примерах — не готовая настройка: используйте адрес своего сервера.

## Как обновлять

Скачайте новую версию, распакуйте и откройте командную строку в её папке. По очереди выполните `npm install --omit=dev`, `homey select`, `homey app install`. Если требуется — предварительно `homey login`.

Не удаляйте старое приложение и не используйте `--clean`. Устройства и Flow должны сохраниться; новые показатели добавляются автоматически.

## Если что-то не получилось

- **Не найдены `node`/`npm`:** завершите шаг 1 и откройте новое окно командной строки.
- **Не найдена команда `homey`:** завершите шаг 2 и откройте новое окно.
- **Не найден `package.json`:** вы не в папке приложения; повторите шаг 4.
- **Homey нет в списке:** проверьте аккаунт Athom, права и подключение Homey к сети.
- **Показаний нет:** проверьте брокер, порт, логин, пароль, TLS и топик. Daly2MQTT уже должен публиковать живые данные; установка приложения не создаёт источник MQTT.
- **Часть параметров пустая:** прошивка должна публиковать эти значения. Приложение не выдумывает отсутствующие данные.
- **Insights пустые:** история начнёт накапливаться с новыми показаниями. Прошлые данные из MQTT задним числом в графики не добавляются.

## Показатели и Insights

История включена для напряжения, тока со знаком, мощности, SOC, остатка Ah/kWh, температур BMS/MOS, дельты ячеек, тока балансировки, FET заряда/разряда, суммарных Ah, циклов, крайних напряжений ячеек, балансировки, Wi-Fi RSSI и сигналов ошибок. Напряжения отдельных ячеек (1–48) и температурные датчики (1–16) добавляются по мере поступления сообщений.

Heartbeat, числовой режим, число ячеек, номера минимальной/максимальной ячейки, реле и ручной режим реле доступны в карточке/Flow, но исключены из Insights. График Wi-Fi сохранён. Числовой режим: 0 — покой, 1 — заряд, 2 — разряд, 3 — offline, 4 — неизвестно.

Порог низкого заряда по умолчанию — 20%. Тайм-аут свежих данных — 300 секунд; 0 отключает проверку. Сохранённые MQTT-сообщения (retained) обновляют значения, но не доказывают, что BMS доступна сейчас. Поддерживаются отдельные топики `<base>/<parameter>`; JSON `Pack_Data` не обрабатывается. HTTP API и команд управления BMS нет. ID приложения: `com.daly.bms`, драйвер: `daly-monitor`. Пароли в журнал не выводятся.
